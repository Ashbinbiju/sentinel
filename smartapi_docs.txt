SmartAPI
AngelOne Ltd. — Developer Documentation
Root Endpoint: https://apiconnect.angelone.in
Introduction
SmartAPI is a REST-like HTTP API suite that provides all the capabilities needed to build a trading algorithm. It allows you to execute orders in real time (equities, commodities), manage user portfolios, stream live market data over WebSockets, and more.
All request inputs and responses are in JSON format. Standard HTTP status codes indicate success and error states. The API endpoints are cross-site request enabled and can be called directly from browsers.
Response Structure
All POST request parameters must be sent as application/json. Responses from the API are always JSON.
Successful Response
{
  "status": true,
  "message": "SUCCESS",
  "errorcode": "",
  "data": {}
}
A successful 200 OK response always has status: true. The data key contains the full response payload.
Failed Response
{
  "status": "false",
  "message": "Login Id or password is invalid",
  "errorcode": "AB1007",
  "data": "null"
}
When status is false, errorcode contains the error code and message contains a textual description of the error.

Authentication with Angel (Login Services)
You can authenticate using your AngelOne Ltd. Account Id. You need a client code, valid PIN, and TOTP. The session remains active until 12 midnight, unless the user logs out.
Login Request
{
  "clientcode": "Your_client_code",
  "password": "Your_pin",
  "totp": "enter_the_code_displayed_on_your_authenticator_app",
  "state": "state_or_environment_variable"
}
Note: State variable is optional. It accepts a string and returns the same string in the response.
Login Response
{
  "status": true,
  "message": "SUCCESS",
  "errorcode": "",
  "data": {
    "jwtToken": "eyJhbGciOiJIUzUxMiJ9...",
    "refreshToken": "eyJhbGciOiJIUzUxMiJ9...",
    "feedToken": "eyJhbGciOiJIUzUxMiJ9...",
    "state": "live"
  }
}
Note: As a best practice, logout every day after activity.
Python Example — Login
import http.client
conn = http.client.HTTPSConnection('apiconnect.angelone.in')
payload = '{"clientcode":"CLIENT_ID","password":"CLIENT_PIN","totp":"TOTP_CODE","state":"STATE_VARIABLE"}'
headers = {'Content-Type':'application/json','X-UserType':'USER','X-SourceID':'WEB',
           'X-MACAddress':'MAC_ADDRESS','X-PrivateKey':'API_KEY'}
conn.request('POST','/rest/auth/angelbroking/user/v1/loginByPassword',payload,headers)
print(conn.getresponse().read().decode('utf-8'))

For users utilizing the new static IP-based API key, the source IP address of Place Order, Modify Order, and Cancel Order requests will be validated against the registered static IP.

Description

WebSocket Streaming 2.0
WebSocket URL
wss://smartapisocket.angelone.in/smart-stream
Features
Simplified and consistent JSON request / binary response structure.
Each client code can maintain up to 3 concurrent WebSocket connections.
Subscribe and unsubscribe on an existing open connection without reconnecting.
Subscription failures do not impact existing subscriptions.
Graceful handling of unsubscribe requests for tokens not currently subscribed.
Total subscription quota: 1000 tokens per WebSocket session.
Subscribing one token to LTP, Quote, and SnapQuote counts as 3 subscriptions.
Duplicate subscriptions to the same token and mode are gracefully ignored.
One tick per token-mode combination is published.
